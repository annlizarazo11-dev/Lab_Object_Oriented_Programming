1. **Computador — ¿Qué ventaja técnica tiene utilizar un constructor frente a crear objetos literales?**

Consideor que la principal ventaja de utilizar un constructor es que permite establecer una estructura común y reutilizarla para crear diferentes objetos, en este caso, todos los computadores tienen marca, procesador, RAM y precio, pero cada uno puede tener valores diferentes

Lo veo como crear una especie de molde: no tengo que construir cada computador desde cero, sino que defino una vez qué información debe tener y después puedo generar diferentes computadores a partir de esa misma estructura. Esto hace que el código sea más organizado y facilita agregar nuevos objetos sin repetir toda la lógica
